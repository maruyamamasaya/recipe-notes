## Project Overview

自分で作った料理の材料、工程、写真をひとつにまとめ、繰り返し活用できる個人向け Web レシピ帳。PC とスマートフォンのブラウザに対応する。

## Goals

- 自分のレシピを完成写真つきの一覧で見返せる。
- 料理名、材料、タグから目的のレシピをすばやく探せる。
- 1人前の材料と写真つき工程を、迷わず記録できる。

目標には、利用者が得られる成果と、可能であれば達成を判断できる基準を記載する。

## Main Use Cases

| ID | 利用者 | 目的 | 成功条件 |
| --- | --- | --- | --- |
| UC-001 | レシピを記録する個人 | 材料と工程を記録する | タイトル、完成写真、材料、1つ以上の工程を保存できる |
| UC-002 | レシピを探す個人 | 過去のレシピを探す | 料理名、材料名、タグのいずれからも絞り込める |
| UC-003 | スマートフォン利用者 | 調理中にレシピを見る | 狭い画面でも横スクロールせず一覧とフォームを操作できる |

## Functional Requirements

| ID | 要件 | 優先度 | 受け入れ条件 | 状態 |
| --- | --- | --- | --- | --- |
| FR-001 | レシピに UUID の一意な ID を発行する | Must | 新規保存ごとに重複しない UUID が付与される | UI 実装済み |
| FR-002 | 完成写真つきレシピ一覧を表示する | Must | 1ページ9件、デスクトップ3列で表示しページ送りできる | UI 実装済み |
| FR-003 | 料理名、材料、タグを横断検索する | Must | 入力に一致しないレシピを一覧から除外する | UI 実装済み |
| FR-004 | 材料名、数量、単位を1人前として登録する | Must | 材料行を追加・削除し、単位を選べる | UI 実装済み |
| FR-005 | 順序つき工程と任意の工程写真を登録する | Must | 工程を追加・削除し、それぞれへ写真を選べる | UI 実装済み |
| FR-006 | 完成写真と工程写真を圧縮する | Must | 長辺1600px以下、目標500KB以下の JPEG に変換する | UI 実装済み |
| FR-007 | レシピを利用者ごとに永続化する | Must | 再訪時にも保存内容を取得でき、別利用者から参照できない | Anonymous Auth で実装済み |
